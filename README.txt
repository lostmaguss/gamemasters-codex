GAMEMASTER'S CODEX
==================

How to start
  Installer: run GamemastersCodex-Setup-1.1.0.exe. It adds Start Menu and desktop shortcuts.
  Portable: unzip this folder anywhere and double-click "Gamemasters Codex.exe".
     Windows may say "Windows protected your PC" because the app isn't signed.
     Click "More info" -> "Run anyway". You only need to do this once.
  3. Optional: right-click the .exe -> "Send to" -> "Desktop (create shortcut)".

Running a session
  Prep  -> plan the next session, then press "Start session".
  Live  -> soundboard, handouts on stream, tonight's secrets, monster HP and attacks, log what happens.
           "End session" saves the time played and moves you to the Chronicle.

Sound on Discord
  Sound plays from the stream window, so share that window with "Sound" switched on in Discord's
  screen-share settings. If your players can't hear it, switch the soundboard to "This window"
  and share your whole screen with sound instead.

Screen-sharing the dice on Discord
  1. Click "Stream dice" in the top bar. A second window called "Codex Dice (stream)" opens.
  2. In Discord: Share Screen -> Applications -> pick "Codex Dice (stream)".
  3. Keep working in the main window. Rolls from the Dice tab are thrown on the stream window.
     In the stream window: H hides the roll history, F goes fullscreen, Space rolls a d20.
     The control bar fades out when the mouse rests.

Where your campaign is saved
  %APPDATA%\Gamemasters Codex\codex-data.json   (a .bak copy of the previous save sits next to it)
  Campaign menu (top-left) -> "Export backup..." saves a copy anywhere you like.

Shortcuts
  Ctrl+1..9  switch sections      Ctrl+S  save now
  Tables: R rolls the open table    Dice: Shift+Enter = secret roll
  Forge:  Space draws a new card
  Board:  double-click cork = new note, drag a pin onto a card = yarn, Del = delete, Ctrl+D = duplicate,
          N = new note, paste or drop an image to pin it
  Dice:   Enter throws, shift-click a die to throw it immediately, right-click a die to remove it from the pool
